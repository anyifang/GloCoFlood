# Pearl River Delta: one-TC example

This example includes one complete historical compound-forcing case for the
Pearl River Delta (PRD). A repository download is sufficient to prepare and
verify the case; global ADCIRC, CaMa-Flood, ERA5 and TC-track archives are not
needed for the default example. The bundled files were generated by the same
production builder, C15/TCR settings, ADCIRC boundary mapping and CaMa-Flood
discharge workflow as the global build.

The reproducible selection is:

- SFINCS domain: `GTC_0009` (PRD);
- ADCIRC block: `ADC_WNP_04`;
- TC event: `track_000261_tracks_GL_era5_197501_201412_000261`;
- rainfall: TCR with the C15 profile selected using
  `gradient_core = surface_core / 0.9`, plus `rescale` for out-of-range Rmax;
- discharge: TC-weighted inlet-cell P50 (`tc_inlet_p50`);
- boundary water level: the matching ADCIRC `fort.63` event.

## Requirements

Create a Python environment and install the small verification dependency:

```bash
python -m pip install -r example/PRD_single_TC/requirements.txt
```

The SFINCS executable is not redistributed. It is only needed if you want to
run the hydrodynamic simulation; preparing and validating the inputs does not
require it.

## Direct run with bundled data

From the `GloCoFlood_public_integration` repository root:

```bash
python example/PRD_single_TC/run_prd_single_tc.py
```

This copies the versioned case data into `example/PRD_single_TC/output` and
checks all required files and NetCDF variables. To run SFINCS immediately:

```bash
python example/PRD_single_TC/run_prd_single_tc.py --sfincs-executable external/bin/sfincs
```

On Windows the final argument can point to `sfincs.exe`; on Linux it can point
to the SFINCS executable or launcher available on that system.

## Reconstruct from the full source datasets

Copy and edit the main path configuration:

```text
SFINCS/global_build/config/paths.example.toml -> SFINCS/global_build/config/paths.toml
```

Then check the external inputs without writing a case:

```bash
python example/PRD_single_TC/run_prd_single_tc.py --full-build --dry-run
```

Generate and automatically verify the case:

```bash
python example/PRD_single_TC/run_prd_single_tc.py --full-build
```

To regenerate an existing example:

```bash
python example/PRD_single_TC/run_prd_single_tc.py --full-build --overwrite
```

The default output is:

```text
example/PRD_single_TC/output/
`-- historical/
    `-- ADC_WNP_04/
        `-- track_000261_tracks_GL_era5_197501_201412_000261/
            `-- GTC_0009/
                |-- sfincs.inp
                |-- sfincs.bzs
                |-- sfincs.dis
                |-- sfincs_precipitation.nc
                |-- sfincs_pressure.nc
                |-- sfincs_wind.nc
                `-- ...
```

The wrapper checks the PRD domain/block membership, required ADCIRC files and
the generated SFINCS files. It also opens the three meteorological NetCDF files
and verifies their time dimension and required variables. Use `--copy-mode
hardlink` only when the source model and output are on the same filesystem and
the output tree will be kept intact; the portable default is `copy`.

The compact event-ready inputs are documented in `data/DATA_PROVENANCE.md` and
checked by `data/MANIFEST.csv`. Large global source datasets are deliberately
not duplicated. They are required only for `--full-build` and must exist at
the locations configured in `config/paths.toml`.
